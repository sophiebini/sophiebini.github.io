# sophiebini.github.io

Personal website. Plain HTML/CSS, served by GitHub Pages.

- `index.html` – welcome page
- `about.html` – about me
- `research.html` – research projects
- `teaching.html` – teaching, mentoring and outreach
- `cv.html` – CV (embeds `files/CV_Bini.pdf`)
- `images/` – photos and figures
- `style.css` – colours and layout (palette variables at the top)

Preview locally: `python3 -m http.server` and open http://localhost:8000
